# OneKOS 飞书工作流配置清单

## 总体数据流

`顾问档案/画像标签/品牌知识/内容任务/内容成果/评论线索/反馈事件 → Aily → 多维表格写回 → 机器人卡片 → 顾问确认 → 下一轮学习`

所有外部平台输入在 PoC 阶段由多维表格模拟导入。将来获得企业和平台授权后，只替换输入节点，不改变 Aily 的结构化处理、数据表和人工门禁。

## WF-01 新顾问校准与画像写回

| 配置项 | 内容 |
|---|---|
| 触发器 | “顾问档案”新增记录，或流程状态变为“待校准” |
| 读取字段 | 顾问ID、城市、门店、从业年限、目标用户、授权状态；历史内容摘要、语音转写和偏好选择 |
| Aily 技能 | `profile_calibration` |
| 条件分支 | 授权状态不完整→请求授权；证据不足→请求一次确认；证据充分→生成标签 |
| 写回字段 | 画像标签：维度、标签、权重、置信度、来源、证据、状态、更新时间；顾问档案：画像成熟度、流程状态 |
| 通知 | 向顾问发送画像确认卡片，可降低、锁定或确认标签 |
| 失败处理 | JSON 解析失败重试 1 次；再次失败写入“校准失败”并通知运营；不生成猜测标签 |
| 人工边界 | 顾问可纠偏、删除或锁定；敏感属性不采集、不推断 |

## WF-02 每日选题与内容包生成

| 配置项 | 内容 |
|---|---|
| 触发器 | 每日 08:45 定时触发，或“内容任务”状态变为“待生成” |
| 读取字段 | 生效画像标签、有效品牌知识、用户问题、模拟平台趋势、近 14 天矩阵内容指纹 |
| Aily 技能 | `daily_topic_route` → 顾问选题确认 → `content_package_generate` |
| 条件分支 | 无有效品牌事实→事实待复核；矩阵角度拥挤→更换空白场景；顾问拒绝→记录反馈且不继续生成 |
| 写回字段 | 内容任务：角度、路由匹配分、画像证据ID、矩阵空白、状态；内容成果：脚本、分镜、素材、事实与画像引用 |
| 通知 | 发送“今日任务卡片”；顾问选择后发送素材确认入口 |
| 失败处理 | Aily 超时或输出不完整时保留“待生成”，记录失败原因并允许运营手动重试 |
| 人工边界 | 顾问补真实素材、轻改并确认；未提供的经历和现场结果不生成 |

## WF-03 四重质检与发布门禁

| 配置项 | 内容 |
|---|---|
| 触发器 | “内容成果”状态变为“待质检” |
| 读取字段 | 标题、脚本、分镜、事实引用、画像引用、近 14 天矩阵指纹 |
| Aily 技能 | `quality_and_matrix_check` |
| 条件分支 | 事实/合规硬门禁失败→阻断；人设证据不足→顾问确认；矩阵高风险→重路由；全部通过→可发布 |
| 写回字段 | 四项质检分、问题清单、撞题记录、空白场景、发布门禁、人工复核原因 |
| 通知 | 通过后通知顾问确认；阻断时向顾问和运营展示具体原因与修正动作 |
| 失败处理 | 知识过期或冲突时停止确定性结论；保留最后有效结果并标注核验时间 |
| 人工边界 | 价格权益、高风险表达、负面舆情和最终发布均需人工确认 |

## WF-04 评论分析、线索接管与策略学习

| 配置项 | 内容 |
|---|---|
| 触发器 | “评论线索”新增模拟评论，或正式接口写入新评论记录 |
| 读取字段 | 原评论、内容ID、平台、授权状态、同步时间、已有顾问和内容信息 |
| Aily 技能 | `comment_to_lead` |
| 条件分支 | A级→立即发送高意向线索卡片；B级→请求补充信息；C级→进入内容培育；负面舆情→运营人工审核 |
| 写回字段 | 主题、情绪、城市、家庭结构、车型、购车时间、试驾意愿、逐字段证据、评分、等级、下一步建议、状态 |
| 后续动作 | 顾问点击接管→状态改为“跟进中”；录入结果→新增反馈事件；顾问确认后更新画像权重 |
| 失败处理 | 字段置信度不足保持为空；同步失败显示最后同步时间；不得伪造实时评论或 CRM 结果 |
| 人工边界 | 不主动联系客户；高意向线索由顾问人工接管；成交结果只接受授权 CRM 或顾问确认 |

## 发布前检查

- Aily 系统提示词已粘贴，五个技能均以 JSON 返回。
- 七张表的 ID 字段设为主字段，跨表关联可以点击跳转。
- 四条工作流分别用一条模拟记录跑通，并能看到状态写回。
- 机器人只对测试群或项目成员可见，正式客户群不在 PoC 范围。
- 所有演示视图均显示“模拟数据”和最后同步时间。
- 顾问只需完成选题、补素材、确认和接管线索四类操作。
