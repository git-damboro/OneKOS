# OneKOS 多维表格字段与视图配置

## 导入顺序

依次导入 `01-顾问档案.csv` 至 `07-反馈事件.csv`。每个 CSV 建议导入为一张独立数据表，并保留第一行为字段名。所有记录均为生成的模拟数据。

## 关联字段

| 数据表 | 主字段 | 需要建立的关联 |
|---|---|---|
| 顾问档案 | 顾问ID | 无 |
| 画像标签 | 标签ID | 顾问ID → 顾问档案 |
| 品牌知识 | 知识ID | 无 |
| 内容任务 | 任务ID | 顾问ID → 顾问档案；画像证据ID → 画像标签 |
| 内容成果 | 内容ID | 任务ID → 内容任务；事实引用ID → 品牌知识；画像引用ID → 画像标签 |
| 评论线索 | 线索ID | 顾问ID → 顾问档案；内容ID → 内容成果 |
| 反馈事件 | 事件ID | 顾问ID → 顾问档案；影响标签ID → 画像标签 |

CSV 中的多值关联使用全角分隔符 `｜`。导入后可批量替换为飞书多选字段或关联记录字段。

## 推荐字段类型

| 字段类别 | 多维表格类型 | 示例 |
|---|---|---|
| ID、标题、证据、脚本 | 文本 | `ADV-017`、脚本正文 |
| 权重、置信度、评分 | 数字 | 91、88 |
| 日期、更新时间、有效期 | 日期 | 2026-08-03 |
| 状态、等级、意图 | 单选 | 待生成、A、强 |
| 画像证据、事实引用 | 关联记录/多选 | TAG-001｜TAG-002 |
| 模拟数据 | 复选框 | 是 |
| 来源 URL | 超链接 | 官方车型页 |

## 推荐视图

| 视图 | 数据表 | 筛选与排序 | 使用者 |
|---|---|---|---|
| 今日待办 | 内容任务 | 任务日期=今天，状态≠已完成；按路由匹配分降序 | 顾问 |
| 画像证据 | 画像标签 | 顾问ID=当前顾问；按权重降序 | 顾问、运营 |
| 待补素材 | 内容成果 | 状态=待顾问补真实素材 | 顾问 |
| 事实到期预警 | 品牌知识 | 有效期至≤未来 14 天或状态≠有效 | 总部运营 |
| 高意向线索 | 评论线索 | 线索等级=A 且状态=待人工接管 | 顾问、店长 |
| 待学习事件 | 反馈事件 | 状态=待顾问确认后学习 | 顾问、系统运营 |

## 权限建议

- 总部运营：可维护品牌知识、质检规则和矩阵策略；不可替顾问编造个人经历。
- 区域运营：可查看本区域任务和矩阵覆盖，不读取无关区域线索明细。
- 顾问：仅查看自己的画像、任务、内容和线索；可纠偏、确认、接管。
- Agent：按工作流最小权限读取和写回，不自动发布、不自动承诺权益、不自动联系客户。
- 评审演示：只展示模拟数据视图，不开放编辑正式知识或外部系统权限。

## 数据保留与异常

- 品牌知识过期或来源冲突时，将内容任务标记为“事实待复核”，禁止进入发布确认。
- 画像证据不足时保留低置信度，不自动补全；通过机器人卡片向顾问请求一次确认。
- 外部数据同步失败时显示最后同步时间，不生成虚假的实时互动。
- 线索识别失败或字段置信度不足时保持为空，高意向线索始终由顾问人工接管。
