# 千面·OneKOS MVP 演示

这是一个完全使用模拟数据的本地网页 MVP，用于演示“抖音评论与互动信号驱动个性化 KOS 内容增长”的完整链路。

## 快速启动

### 方法一：双击启动

双击 `启动演示.bat`，等待浏览器自动打开。

### 方法二：命令行启动

```powershell
cd E:\Desktop\BISAI\OneKOS_MVP演示
npm start
```

然后访问：`http://127.0.0.1:4173`

演示结束后，在服务器窗口按 `Ctrl+C` 停止服务。

## 演示安全边界

- 评论、用户、播放、点赞、收藏、转发、完播率和销售线索全部为模拟数据。
- 不访问抖音开放平台，不读取真实账号或用户信息。
- 不连接飞书、CRM、试驾系统或大模型服务。
- 不会真实发布视频、回复评论、发送私信或触达客户。

## 测试
