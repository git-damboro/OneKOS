# 千面·OneKOS｜飞书落地操作手册

## 目标与完成标准

本手册用于将仓库中的飞书配置包搭建成周三演示 PoC。完成后，评委能够在飞书中看到至少一条真实运行的数据链：任务状态触发 → Aily 生成结构化结果 → 写回多维表格 → 发送机器人卡片 → 顾问点击后更新状态。

| 项目 | 完成标准 |
|---|---|
| 多维表格 | 七张表已导入，主键和跨表关联可点击 |
| Aily | 五项技能已配置，至少两项可真实调用 |
| 工作流 | 至少跑通 WF-02 选题/内容生成和 WF-04 评论转线索 |
| 机器人 | 能收到今日任务和 A 级线索卡片，按钮能写回状态 |
| 演示数据 | 全部显示“模拟数据”、授权状态和最后同步时间 |
| 人工门禁 | 最终发布、价格权益和高意向线索均需人工确认 |

## 二、创建多维表格

1. 在飞书创建多维表格，命名为“千面·OneKOS 运营中台（复赛演示）”。
2. 依次导入七份 CSV，每份新建为独立数据表，并将名称改为：顾问档案、画像标签、品牌知识、内容任务、内容成果、评论线索、反馈事件。
3. 将各表的 ID 字段设为主字段：顾问ID、标签ID、知识ID、任务ID、内容ID、线索ID、事件ID。
4. 把权重、置信度、评分和画像成熟度改为数字；日期和有效期改为日期；状态、等级、意图改为单选；来源 URL 改为超链接；模拟数据改为复选框。
5. 按以下顺序建立关联，避免引用目标不存在：

| 当前表 | 当前字段 | 关联目标 |
|---|---|---|
| 画像标签 | 顾问ID | 顾问档案.顾问ID |
| 内容任务 | 顾问ID | 顾问档案.顾问ID |
| 内容成果 | 任务ID | 内容任务.任务ID |
| 评论线索 | 顾问ID、内容ID | 顾问档案、内容成果 |
| 反馈事件 | 顾问ID、影响标签ID | 顾问档案、画像标签 |

多值画像证据和事实引用在 CSV 中使用 `｜` 分隔。演示版可以先保留文本；时间允许时再拆成多选或多关联字段。

## 三、建立六个演示视图

| 视图 | 筛选 | 排序 |
|---|---|---|
| 今日任务 | 任务日期=今天，状态≠已完成 | 路由匹配分降序 |
| 我的画像 | 顾问ID=ADV-017，状态≠停用 | 权重降序 |
| 待补素材 | 内容状态=待顾问补真实素材 | 创建时间升序 |
| 事实到期预警 | 有效期在未来 14 天内，或状态≠有效 | 有效期升序 |
| A 级线索 | 线索等级=A，状态=待人工接管 | 线索分降序 |
| 待学习事件 | 状态=待顾问确认后学习 | 创建时间降序 |

在每个视图顶部增加说明：“本视图全部为生成的模拟演示数据，不对应真实员工、账号或客户。”

## 四、配置 Aily Agent

1. 在 Aily 创建自定义智能体，名称设为“千面·OneKOS 内容搭档”。
2. 将 `OneKOS-Agent系统提示词.md` 全文复制为系统提示词。
3. 连接刚创建的多维表格，按最小权限授权七张表的读取和必要字段写入。
4. 将品牌知识表或飞书知识空间配置为事实检索来源；测试时确认状态、核验日期和有效期会一起返回。
5. 创建五个技能，名称必须与提示词一致：

| 技能 | 首轮是否必须跑通 | 演示输入 | 写回目标 |
|---|---|---|---|
| `profile_calibration` | 可选 | 顾问档案＋画像证据 | 画像标签、画像成熟度 |
| `daily_topic_route` | 必须 | 画像＋用户问题＋矩阵空白 | 内容任务 |
| `content_package_generate` | 必须 | 已选任务＋品牌知识 | 内容成果 |
| `quality_and_matrix_check` | 推荐 | 内容成果＋矩阵样本 | 四项质检分、发布门禁 |
| `comment_to_lead` | 必须 | 一条模拟评论 | 评论线索 |

6. 每项技能要求输出合法 JSON；将字段映射到对应数据表。解析失败时不继续写回，并记录失败原因。

## 五、配置工作流

### 最小演示流程 A：选题到内容写回

1. 触发器：内容任务记录状态变为“待生成”。
2. 读取：顾问档案、对应画像标签、有效品牌知识、任务问题和矩阵空白。
3. 调用：`content_package_generate`。
4. 条件：`fact_ref_ids` 为空或知识过期时，将状态改为“事实待复核”；否则创建/更新内容成果记录。
5. 写回：脚本、分镜、素材、事实引用、画像引用，内容状态设为“待顾问补真实素材”。
6. 通知：发送今日任务或内容确认卡片。

### 最小演示流程 B：评论到 A 级线索

1. 触发器：评论线索表新增一条原评论，状态为“待识别”。
2. 调用：`comment_to_lead`。
3. 写回：城市、家庭结构、车型、购车时间、试驾意愿、字段证据、评分、等级和下一步建议。
4. 条件：等级=A 时发送高意向线索卡片；B 级进入补充信息视图；C 级进入内容培育。
5. 顾问点击“我来接管”后，把状态改为“跟进中”，不触发任何对外联系。

完成上述两条后，再按 `工作流配置清单.md` 添加 WF-01 和 WF-03。

## 六、配置机器人卡片

1. 将 `今日任务卡片.json` 和 `高意向线索卡片.json` 复制到飞书卡片搭建工具。
2. 将 `{{数据表.字段}}` 占位符映射为工作流变量。
3. “选择这个任务”按钮写回内容任务状态为“已选择”；“今天不适合”写回“顾问拒绝”并新增反馈事件。
4. “我来接管”按钮写回线索状态为“跟进中”；“信息不足”写回“待补充信息”。
5. 机器人仅发布到项目测试群，卡片底部始终显示 SIMULATION 说明。

## 七、演示前自检

| 检查动作 | 预期结果 |
|---|---|
| 把 TASK-001 状态改为“待生成” | Aily 生成 CONTENT-001 并写回内容成果 |
| 打开内容成果 | 能看到事实引用和画像引用，不出现凭空经历 |
| 触发四重质检 | 事实、合规、人设、矩阵均有分数；高风险会阻断 |
| 新增模拟试驾评论 | 城市、车型、时间、意愿和逐字段证据被提取 |
| 查看 A 级线索视图 | 新线索出现并收到机器人卡片 |
| 点击“我来接管” | 线索状态变为“跟进中”，不对外触达 |
| 新增跟进结果 | 生成反馈事件，顾问确认后画像权重更新 |

| 时间 | 操作 | 讲解重点 |

## 九、当前真实与模拟边界

| 已真实实现/可配置 | 当前模拟 |
|---|---|
| 七张多维表格数据模型、Aily JSON 契约、工作流状态、机器人卡片、数据写回规则 | 顾问资料、历史内容、抖音评论、点赞收藏转发、CRM 结果 |
