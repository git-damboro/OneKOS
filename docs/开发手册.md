## 画像初始化状态机

顾问状态：`uninitialized → collecting → pending_confirmation → active`

会话状态：`draft → generated → confirming → confirmed`；异常状态为 `generation_failed`、`write_failed`。

## 接口索引

所有公开响应不得包含密钥或敏感外部用户标识。

| 方法 | 路径 | 用途 |
|---|---|---|
| `GET` | `/api/advisors` | 列出可选择的顾问 |
| `POST` | `/api/advisors` | 创建 Web 模拟顾问身份 |
| `POST` | `/api/onboarding/sessions` | 创建画像初始化会话 |
| `GET` | `/api/onboarding/sessions/:sessionId` | 恢复初始化进度 |
| `POST` | `/api/onboarding/sessions/:sessionId/generate` | 生成候选画像 |
| `POST` | `/api/onboarding/sessions/:sessionId/confirm` | 确认画像 V1 与首条任务 |

确认接口支持 `Idempotency-Key` 请求头，重复请求返回同一画像版本和任务。

## 数据表

当前已有七张 OneKOS 业务表；本功能将新增“画像初始化会话”表，用于恢复、重试和幂等确认。
