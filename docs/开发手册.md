# OneKOS 开发手册

## 维护规则

- 本文件是项目持续开发记录；每次功能、接口、数据结构、配置或验证方式发生变化时，必须随同代码一起更新。
- 所有新功能在独立分支按测试驱动方式开发，用户验收前不合并 `main`、不推送远端。
- 文档中的“已完成”必须有自动化测试、smoke 或人工验收证据。
- 不在文档、日志、截图或提交中记录飞书 Secret、模型 API Key 等敏感信息。

## 画像初始化状态机

顾问状态：`uninitialized → collecting → pending_confirmation → active`

会话状态：`draft → generated → confirming → confirmed`；异常状态为 `generation_failed`、`write_failed`。

## 接口索引

初始化接口将在开发过程中补充，所有公开响应不得包含密钥或敏感外部用户标识。

## 数据表

当前已有七张 OneKOS 业务表；本功能将新增“画像初始化会话”表，用于恢复、重试和幂等确认。
